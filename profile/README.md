## Four Beats

1. **Name the census.** Give the Total Network Inventory session a short title before you run an asset scan on devices you are authorized to manage.
2. **Pin the live assets.** Keep current hardware and software rows on the Total Network Inventory board and leave unused hosts aside.
3. **Check the report.** Read the Total Network Inventory summary of the software report before you treat a census as final.
4. **Close the loop.** Note which lists are ready so the next Total Network Inventory visit does not start by hunting the hardware list.

## First Questions

**Does Total Network Inventory replace the ticket desk?**  
No. Total Network Inventory sits beside the tickets and the device list you already keep for hosts you are authorized to manage.

**Can two admins share one computer?**  
Yes. Each person keeps a separate Total Network Inventory profile for the same authorized LAN.

**Will Total Network Inventory stay workable on an older office laptop?**  
Yes. Total Network Inventory is meant to stay light during a normal census session on that desk.

**What should a new user try first?**  
One small Total Network Inventory asset scan today on devices you are authorized to manage, then the same network census again tomorrow.

## Field Note

Total Network Inventory is easier to trust when the census stays smaller than the LAN it came from. A named session shows which authorized set is active, the pins show which hosts you will read today, and the closing note tells the next person which asset scan drives the hardware list and the software report. That record is short on purpose: not a copy of every file on every PC, only the path back to devices the reader is authorized to manage.

The same loop fits a campus lab you run, a client site you are assigned, or a computer shared by two admins. Open the last Total Network Inventory session, confirm one hardware list, and leave the network census easier to follow than you found it. Other programs stay where they are. Total Network Inventory only holds the asset scan, the software report, and the handoff.

## One Real Pass

Pick a LAN slice that already has a name and that you are authorized to manage: a lab row, an office floor, or a short set of PCs on your desk. Open it in Total Network Inventory, keep only those hosts on the board, and read one hardware list you can point to. A pass is done when that list stays tied to the asset scan and the unused hosts are no longer in the way. Total Network Inventory does not need a full rebuild of the census before it is useful.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different job and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first asset scan to the last software report, with the summary still matching the network census on that desk.
